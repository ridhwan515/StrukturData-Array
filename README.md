## Deskripsi Tugas
### Buat program (Java dan Python) menggunakan struktur data array (fixed-size array) dengan kapasitas 10, untuk menyimpan sejumlah data mahasiswa (nim dan nama). Program memiliki menu sebagai berikut:
1. Insert at beginning (data baru ditempatkan di blok pertama)
2. Insert at given position (data baru ditempatkan di blok nomor sesuai pilihan)
3. Insert at end (data baru ditambahkan setelah data terakhir)
4. Delete from beginning (hapus data di blok 1)
5. Delete given position (hapus data di blok yang dipilih)
6. Delete from end (hapus data terakhir)
7. Delete first occurence (hapus data pertama yang ditemukan)
8. Show data (tampilkan semua data di array)
9. Exit
0. Refresh (opsional)

## Struktur File
*   `array.py`: Implementasi program menggunakan Python.
*   `FixedArrayApp.java`: Implementasi program menggunakan Java.
*   `prompt.txt`: Dokumentasi prompt AI yang digunakan selama pengerjaan tugas.
